Mala Direta para Google Docs

Gere documentos personalizados em massa (.docx ou .pdf) a partir de um modelo do Google Docs e uma planilha do Google Sheets — tudo dentro do navegador.

Disponível na Chrome Web Store Gratuito Código aberto

Como funciona

Em 3 passos simples você transforma um modelo e uma lista de dados em dezenas ou centenas de documentos personalizados:

1

Prepare o modelo

Crie um Google Docs com tags no formato {{Campo}} onde os dados devem entrar (ex.: Prezado(a) {{Nome}}).

2

Prepare a planilha

No Google Sheets, a primeira linha contém os nomes dos campos (Nome, Email, etc.) e cada linha seguinte é um destinatário.

3

Gere os documentos

Abra a extensão no documento modelo, selecione a planilha, escolha formato (.docx/.pdf) e pasta de destino. Clique em Gerar.

Principais recursos

📄

Dois formatos de saída

Gere .docx (editável no Word) ou .pdf (pronto para impressão/envio).

☁️

Salva no Google Drive

Arquivos organizados na pasta que você escolher — inclusive Unidades compartilhadas.

💾

Download local (ZIP)

Opção de baixar todos os arquivos compactados em um único .zip na pasta Downloads.

🏷️

Inserção de tags no cursor

Clique nos chips de campos no painel lateral para inserir {{Campo}} direto no documento.

📊

Log completo de operações

Histórico com data, hora, arquivo, formato, status e erros — exportável em CSV/JSON.

🔒

Privacidade total

Seus dados nunca saem do seu navegador. A extensão usa suas credenciais OAuth diretamente nas APIs do Google.

Requisitos

⚙️ O que você precisa

  • Conta Google (pessoal ou Workspace)
  • Google Docs API, Drive API e Sheets API ativadas no seu projeto no Google Cloud Console
  • Um Client ID OAuth (tipo "App para computador") configurado na extensão (veja SETUP.md)

Limite: até 1.000 linhas por execução. O log guarda as últimas 50 operações.
